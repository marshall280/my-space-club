# My Space Club

**My Space Club** est mon site personnel. Je m'appelle Marshall, je viens du Bénin et j'utilise ce site pour garder une trace de ce que j'apprends et des projets que j'aimerais construire.

## Pourquoi j'ai créé ce site

Je m'intéresse à l'informatique, Python, la programmation, la robotique, l'électronique et les technologies spatiales.

Je ne veux pas présenter ces sujets comme si je les maîtrisais déjà. Le site évolue avec moi : j'ajoute mes apprentissages, mes essais, mes idées et parfois les problèmes que je rencontre.

Un de mes projets à long terme est de construire un ROV sous-marin capable d'explorer les eaux du Bénin. Pour l'instant, c'est surtout un projet d'apprentissage : je dois encore comprendre beaucoup de choses avant de fabriquer un prototype.

## Tech utilisée

- HTML
- CSS
- JavaScript vanilla
- GitHub Pages

Le projet reste volontairement simple : les pages principales sont des fichiers HTML/CSS/JavaScript sans framework.

## Ce qui fonctionne

- site responsive pour téléphone et ordinateur
- navigation avec menu mobile
- journal de bord avec filtre par catégorie
- apparition discrète des sections avec `IntersectionObserver`
- navigation fluide entre les sections
- page dédiée au projet Stardance
- page dédiée au projet ROV
- HTML sémantique et accessibilité pris en compte quand nécessaire

## Structure du projet

- `index.html` — site principal
- `stardance.html` — page du projet Stardance
- `README.md` — documentation du projet

## Ce que j'apprends en construisant le site

Je travaille progressivement sur HTML, CSS, Flexbox, responsive design, JavaScript, manipulation du DOM et Git/GitHub.

Le site n'est pas considéré comme terminé. Je veux continuer à l'améliorer au fur et à mesure que je comprends mieux le développement web.

## Stardance

Ce projet est destiné à la mission **Personal Site** de Stardance 2026.

Le projet est open source, le dépôt est public et le site est prévu pour être déployé avec GitHub Pages. La page `stardance.html` documente les objectifs et l'évolution du projet.
